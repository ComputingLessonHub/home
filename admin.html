    Backups and devices

    Weekly backup

    Downloads the entire database as one file. Keep it somewhere safe if something goes badly wrong, it is what you would put back.

    Import backup

    Only if something has gone wrong. Take a backup first, so there is a way back if this makes things worse.

    How much room is being used

    There is 25GB in total, shared by every year. Screenshots take up far more room than anything else.

    Signed-in devices

    Browsers that have answered a code from the authenticator app. Each one can sign in with the key alone until its sixty days are up. Give them names you will recognise. Sign the others out if a machine has been lost, or if there is anything here you cannot account for.
